# Implementation Plan

## Phase 1: Foundation (1 week)
App scaffold, database, Prisma migrations, authentication, RBAC, shell, CI checks.

## Phase 2: Projects and Subcontractors (1–2 weeks)
Project CRUD, subcontractor CRUD, project/company membership, assignment and budget allocation.

## Phase 3: Expense Tracking (1–2 weeks)
Expense forms with multiple items, server-side totals, categories, receipt storage, status transitions.

## Phase 4: Approval and Budget Controls (1–2 weeks)
Atomic approval/rejection, budget adjustment audit, utilization alerts, dashboard.

## Phase 5: Reports and Administration (1 week)
Reports, CSV export, user administration, audit log.

## Phase 6: Verification and Deployment Readiness (1–2 weeks)
Unit/integration/e2e tests, concurrency and authorization checks, production build, deployment guide.

Overall estimate: ~6–10 weeks for one experienced full-stack developer, subject to requirements and external dependencies. Agent runtime and completion are not guaranteed.
